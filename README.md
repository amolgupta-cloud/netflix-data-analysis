# Netflix Data Analysis

## About the Project

This project explores the Netflix titles dataset using Python and Pandas. The analysis looks at movies and TV shows across different categories to understand patterns in Netflix content.

## Tools & Skills

- Python
- Pandas
- Jupyter Notebook
- Data Cleaning
- Data Analysis
- Data Visualization

## Key Analysis

- Movies vs TV Shows
- Content ratings
- Top countries by number of titles
- Release year trends
- Top directors
- Movie duration analysis
- Distribution of ratings

## Dataset

The project uses the Netflix titles dataset containing information about movies and TV shows available on Netflix.

## Objective

The goal of this project was to practice using Python and Pandas to clean, explore, and analyze a real-world dataset and turn the results into meaningful insights.
